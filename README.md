# nusantara-angka

[![make.fun · best-national-statistics-site-20261126-0539](https://make.fun/badge/best-national-statistics-site-20261126-0539.svg)](https://make.fun/bounty/best-national-statistics-site-20261126-0539?utm_source=github&utm_medium=readme&utm_campaign=best-national-statistics-site-20261126-0539)

Nusantara Angka — a pocket atlas of Indonesia's official statistics. Nine bundled
time series (population, growth, inflation, poverty, life expectancy, internet use,
literacy, unemployment, electrification), province comparisons, GDP structure and
trade partners, a milestone timeline and a data provenance page — all offline, no
network requests, on desktop or phone, with light/dark themes and chart tooltips.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. (No build step: `app/` is plain static files.)
